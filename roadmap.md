# Roadmap

- [ ] Persistă regulile de securitate și remedierile validate pentru auto-reparare.
- [ ] Audit și întărire server-side pentru verificare înainte de discover, profil, mesaje și interacțiuni.
- [ ] Profil user 360 pentru utilizatorul final, fără expunerea datelor sensibile sau a locației precise.
- [ ] Push nativ pentru foreground/background/terminated, cu preferințe și consimțământ respectate.
- [ ] Remindere zilnice pentru conturi neverificate, prin coada push DB-driven și limitare anti-spam.
- [ ] UX Android: lifecycle, back, safe area, încărcare și stări de eroare.
- [ ] Teste țintite, build, preview real și verificare finală a tuturor item-urilor.
